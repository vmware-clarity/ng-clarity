## Import

- Modules used in the demos: `ClarityModule`
- Granular module for a lean bundle: `ClrA11yModule` (confirm in the API report below)
- Consumer app code may be standalone + OnPush + Signals; Clarity APIs stay decorator-based; icons use `cds-icon`.

## API observed in the demos

- Elements: `clr-input-container`, `clr-tab`, `clr-tab-content`, `clr-tabs`
- Directives / inputs: `clrForm`, `clrInput`, `clrLayout`, `clrTabLink`
- CSS classes: `clr-required-mark`
