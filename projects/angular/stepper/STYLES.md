# Stepper

## CSS Custom Properties

| CSS Custom Property                          | Description                                                      |
| -------------------------------------------- | ---------------------------------------------------------------- |
| --clr-stepper-error-color                    | Color of the error state icon and indicator.                     |
| --clr-stepper-complete-color                 | Color of the complete state icon and indicator.                  |
| --clr-stepper-header-left-indicator          | Left box-shadow indicator of a step header in its default state. |
| --clr-stepper-header-left-current-indicator  | Left box-shadow indicator of the currently open step header.     |
| --clr-stepper-header-left-complete-indicator | Left box-shadow indicator of a completed step header.            |
| --clr-stepper-header-left-error-indicator    | Left box-shadow indicator of a step header with an error.        |

## CSS Classes

| Class Name                         | Description                                                              |
| ---------------------------------- | ------------------------------------------------------------------------ |
| clr-stepper-forms                  | Main stepper container (`form[clrStepper]`).                             |
| clr-stepper-has-step-description   | Stepper container when at least one step panel has a description.        |
| clr-stepper-panel                  | Panel within the stepper.                                                |
| clr-stepper-panel-disabled         | Disabled state of a stepper panel.                                       |
| clr-stepper-panel-open             | Open or expanded state of a stepper panel.                               |
| clr-stepper-panel-complete         | Completed state of a stepper panel.                                      |
| clr-stepper-panel-error            | State of a stepper panel with a validation error.                        |
| clr-stepper-header                 | Header section of a stepper panel.                                       |
| clr-stepper-header-button          | Clickable button within the stepper header.                              |
| clr-stepper-header-has-description | Stepper header of a panel that has a description.                        |
| clr-step-status                    | Status indicator within the stepper header.                              |
| clr-step-status-icon               | Icon wrapper within the step status indicator.                           |
| clr-step-error-icon                | Error icon shown within the step status indicator.                       |
| clr-step-complete-icon             | Complete icon shown within the step status indicator.                    |
| clr-stepper-angle                  | Angle/arrow indicator within the stepper header.                         |
| clr-step-angle                     | Angle/arrow indicator within the stepper header (responsive visibility). |
| clr-step-title-wrapper             | Wrapper around the step number and title.                                |
| clr-step-number                    | Step number within the step title wrapper.                               |
| clr-stepper-title                  | Title text within the stepper header.                                    |
| clr-stepper-description            | Description text within the stepper header.                              |
| clr-stepper-content-region         | Content region section of a stepper panel.                               |
| clr-stepper-content                | Content section of a stepper panel.                                      |
| clr-stepper-inner-content          | Inner content section within the stepper content.                        |
| clr-step-button                    | Navigation button used to move between stepper panels.                   |
