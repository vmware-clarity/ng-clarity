Column actions

Setting enableColumnActions on an appfx-datagrid puts a kebab menu in every column header, offering Move Left and Move Right. The menu is off by default - the toggle below drives that input, so turning it off takes the kebab out of every header again.

A column that is sortable or filterable gets Sort Ascending / Sort Descending and Filter Column in the same menu automatically, alongside the existing column title and filter icon. Adding pinnable to a column definition adds Pin Column / Unpin Column too.

A pinned column is rendered in the sticky container and the rest in the scrollable one, so Move Left / Move Right step a column within its own group and never across the boundary. Pin VM Name and State, and they can be reordered with each other while the loose columns keep stepping among themselves.

An application can add its own items after the built-in ones, from either level of the configuration. columnActions on the grid applies to every column - Copy column values and the disabled Column details below - while actions on a single column definition applies only to that one, which is how Show as relative time appears on Creation date alone. Column actions are appended after the grid ones, and both are reported through the grid's actionClick output with the column definition as the event context. An action naming an icon shape needs that shape registered by the application.
