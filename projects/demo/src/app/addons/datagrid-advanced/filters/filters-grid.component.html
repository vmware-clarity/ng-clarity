Combined filter

The quick search and the filter pills work together: rows must match the search text and every filter. Clear all removes both.

Predefined filters

VM Name and Status stay visible when cleared. VM Name starts with three conditions: contains linux, windows, or ubuntu. Status starts with Warning and Alert selected. Priority and Category are semi-predefined filters: click their option pills to toggle them. State: Powered On is an on/off filter. Open VM Name to add or remove conditions, or use Add filter to filter by other fields.
