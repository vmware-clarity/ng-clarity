Pinnable columns

A column definition with pinned is rendered to the left of the scrollable columns and stays visible while the grid is scrolled horizontally.

VM Name and Status start pinned, and the remaining columns are scrollable.

Adding pinnable adds Pin Column / Unpin Column to that column's actions menu, so the user can pin and unpin the column themselves.

VM Name and Status start pinned and are both pinnable, State is pinnable but starts loose, and Used space, CPUs and Creation date cannot be pinned at all.

The pinned columns are rendered together in front of the rest, whatever order they are defined in, so the order on screen is not the order of the column definitions. Move Left and Move Right follow what is on screen: each column moves within its own group, so the pinned columns reorder with each other and the scrollable ones among themselves, and only the real edges of a group are disabled.
