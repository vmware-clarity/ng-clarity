Pinnable columns

A column definition with pinned is rendered to the left of the scrollable columns and stays visible while the grid is scrolled horizontally. Adding pinnable puts a pin toggle in the column header, so the user can pin and unpin the column themselves.

VM Name starts pinned and is pinnable, State and Status are pinnable but start loose, and the remaining columns cannot be pinned at all.
