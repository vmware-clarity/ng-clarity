Datagrid: Column actions

clr-dg-column-actions gathers the actions of a single column behind one menu in the column header. It is opt-in per column, and it only offers what the column can already do - the behaviour stays on clr-dg-column, so the menu and the header controls cannot drift apart.

The column title keeps its own click-to-sort, so the menu is an additional, more explicit way to reach it. The filter is different: a column that has one gets a Filter Column action automatically and its filter toggle steps aside, so the header keeps one control per column instead of two.

Sorting from the menu

Every column below is sortable, so the menu offers Sort Ascending and Sort Descending, and the active direction is marked. Clear Sort only appears once the column is sorted. The last column sets clrDgDisableUnsort, so it never offers Clear Sort - the menu will not undo what that input asked for.

Custom column actions

Items projected into clr-dg-column-actions are appended after the built-in ones and have to carry clrDgColumnAction. That directive is what joins them to the menu's arrow key order and closes the menu when one is picked. clrDropdownItem cannot be used here: it resolves its dropdown from where it is declared, which is outside the menu in the component's own template.

Custom items take an icon the same way the built-in ones do, which is what keeps the labels in the menu aligned with each other.

The filter moves into the menu

All three columns below have a filter through clrDgField, but only the first two have an actions menu. Compare their headers: the first two show no filter funnel and offer Filter Column in the menu instead, while the third keeps its funnel. Filtering from the menu opens the same popover, anchored to the menu trigger.

Filter one of the first two columns and then close the menu: the trigger stays highlighted, because with the funnel gone it is the only thing left to show that the column is filtered.
