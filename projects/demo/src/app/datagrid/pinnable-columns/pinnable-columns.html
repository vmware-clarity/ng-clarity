Datagrid: Pinnable columns

A column with clrDgPinned is rendered to the left of the scrollable columns and stays visible while the rest of the datagrid is scrolled horizontally. Pinned columns keep their declaration order and are placed after the built-in row controls.

Keeping the pinned state in sync

The columns below bind [clrDgPinned], so ticking a checkbox pins the matching column. A one-way binding is enough here because none of these columns is clrDgPinnable, so nothing inside the datagrid can change the pinned state. Add clrDgPinnable and a two-way [(clrDgPinned)] binding to follow a change the user made through the actions menu - that is what clrDgPinnedChange is for, and the "Column actions" demo shows it.

With row controls

Selection, row actions and the expand caret keep their place at the very left. The pinned columns follow them, and the separator after the last pinned column marks the boundary with the scrollable ones.

With the detail pane

The detail pane shows a single, full width column, so there is nothing left to scroll. Pinning is suspended for as long as the pane is open and restored when it closes - the clrDgPinned input itself is not touched.
