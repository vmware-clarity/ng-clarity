Expand all performance

A generated recursive tree to measure expandAll(), collapseAll(), expandDescendants() and collapseDescendants() on a large amount of nodes. In eager mode every node is in the DOM from the start, so a bulk operation is pure state change plus one change detection pass. In lazy mode children are fetched on expand, so expand all cascades level after level and the "settled" column is the one to look at.
