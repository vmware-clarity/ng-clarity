Services

ClrContextEngineService

Root-provided. Builds snapshots on demand and owns the two ways context leaves the application.

Member Returns Effect
getSnapshot(options?) ClrPageContext Describes the page as it is at this moment. Nothing is cached, so a snapshot cannot report UI that has been closed, destroyed or navigated away from.
registerDomExtractor(extractor) () => void Teaches the collector about markup that carries neither an ARIA role nor an accessible name. Returns a function that removes it again.
enableFrameBridge(options?) void Starts answering context requests from embedded frames. Same-origin only unless told otherwise. A frame receives neither form values nor the page's address — only the route pattern, such as clusters/:id, and links without their query strings — unless the host sets shareFormValues or shareFullUrl. A frame's budgets are capped at the host's own snapshot budgets, and at the defaults wherever the host set none.
disableFrameBridge() void Stops answering frames.
requestHostContext(options?) Promise<ClrPageContext | null> For an application that is itself embedded: asks the hosting page for its context. Resolves with null when the host does not answer, so embedded UI degrades gracefully.
enableGlobalAccess(propertyName?, options?) void Exposes window.clrContext() for agents driving the browser. Because any script on the page can call it, the caller is treated as untrusted: only the options in CLR_CONTEXT_UNTRUSTED_OPTION_KEYS are honoured (budgets, categories, roles, focus, collection mode — never selectors), each held to what the application allows through options here and provideClrContextOptions, and to the defaults wherever neither says: a caller cannot turn on includeRoutes or raise maxComponents past them. What the user entered — typed values, chosen options, ticked boxes, selected rows — is withheld unless shareFormValues is set, and the page's address is reduced to its route pattern, with links losing their query strings, unless shareFullUrl is set.
disableGlobalAccess() void Removes the global accessor.

ClrContextTrackerService

Root-provided. Turns the pull-based engine into a stream for consumers that always want the current page.

Member Type Effect
context$ Observable<ClrPageContext> Emits whenever the page context actually changes, replaying the most recent snapshot to new subscribers.
currentContext ClrPageContext | null The most recent snapshot, or null before tracking starts.
isTracking Boolean Whether the tracker is watching the page. The tracker is shared: a consumer that only wants to look can check this and leave starting and stopping to whoever owns tracking.
start(options?) void Takes a snapshot immediately, then watches the DOM for changes and input / change for typing. Calling it again restarts with the new options.
stop() void Stops tracking. The last emitted context stays available.
refresh() void Takes a snapshot immediately and emits it.
changes$ Observable<ClrContextChange> Emits, alongside every context$ emission, what changed since the previous one — nodes added, removed and changed, and whether the route, title or annotations moved — so a conversation can send the difference rather than the whole page. diffClrContext(previous, current) is the same comparison as a function.

ClrMutationEngineService

Root-provided. The write half: gives Angular-bound form controls values and navigates, from the refs and routes in the latest snapshot. Inert until the application provides a ClrMutationPolicy. Available to application code only.

Member Returns Effect
apply(operations, snapshotOptions?) Promise<ClrMutationReport> Applies the operations in order — setValue, clear, navigate — and reports what each did, then a fresh snapshot taken with snapshotOptions and the difference from the page before. A refused operation does not stop the ones after it. Calls run one at a time: a call made while another is running waits for it. Each operation is resolved again after a confirmation, and refused as stale if its target changed while the person was deciding.
plan(operations) ClrMutationPlanEntry[] What applying the operations would do, without doing it: each target resolved, classified and its value translated, or the refusal it would meet.

Operations

Operation Fields Effect
setValue ref, description, value Gives the control a value, in the agent's terms: text, a number, true or false, an option's label (or one per item for a multi-select), a date or ISO string, the rows to select. The description is the node's label as the agent knows it, and is checked against the node before anything is written.
clear ref, description Empties the control, so a model can say "no value" deliberately.
navigate path, params?, queryParams? Goes to a route from availableRoutes through the router, with the pattern's parameters filled in. Each parameter fills one path segment literally — a slash or a space stays part of the value — and . or .. is refused. Guards run; the outcome is read from the router's events. A route whose module has not loaded yet is listed as lazy, and its own routes once it has.

Results

Property Type Description
applied Boolean Whether the operation took effect.
value, previous unknown The control's value now, in the agent's terms — which may differ from what was asked for — and before, so the application can revert.
status, errors String, Object The form control's validity after the write (VALID, INVALID, PENDING, DISABLED) and its validation errors, so a failure is part of the result.
outcome, url String For a navigation: navigated, redirected, unchanged, rejected, superseded or failed, and the URL the page is now at.
refused, detail String Why an operation was not applied, and what to do about it: unclassified, forbidden, unconfirmed, declined, stale, mismatch, hidden, redacted, disabled, readOnly, unbound, unsupported, invalid or noRoute.

ClrMutationPolicy

Provided with provideClrMutationPolicy(policy). Providing one is what enables mutations: without it snapshots carry no refs and every operation is refused as unclassified.

Member Returns Effect
classify(target) 'reversible' | 'consequential' | 'forbidden' Declares what an operation would do, given its resolved target: the node's ref, label, type and element, the value about to be written in the agent's terms (an option's label, not its bound object, which is in modelValue), or the route, URL and query parameters. The engine never infers this; a policy that throws or answers anything else forbids. Judge the element or the form control rather than the label: a label is translated, and can repeat.
confirm(target) boolean | Promise<boolean> Optional. Asked before a consequential operation is applied; false refuses it as declined. A consequential operation with no hook to ask is refused as unconfirmed.
announce(report) void Optional. Told what an apply() did once it is done, so the application can let the person know — through a live region or a message — which fields were filled for them and which now show an error. The engine announces nothing itself: the words, and the language, are the application's.

ClrContextRegistryService

Root-provided. Holds whatever can contribute application knowledge to a snapshot. Providers are polled at snapshot time and nothing is stored, so an annotation cannot go stale.

Member Returns Effect
register(provider, element?) () => void Registers a ClrContextProvider. Returns a function that unregisters it. Given the element the annotation sits on, the annotation follows that element's fate: left out when the element is hidden, ignored or outside the snapshot root, and reported without its state inside a redacted region. [clrContext] passes its host element.
unregister(provider) void Removes a provider, typically from ngOnDestroy.

Directives

[clrContext]

Annotates a region with the knowledge only the application has. Ships in ClrContextModule.

Input Values Default Effect
clrContext String — What this region is about, in words an agent can use.
clrContextType String 'region' The kind of UI this annotation describes.
[clrContextState] Object null Application state worth knowing, read at snapshot time rather than stored, so it is never out of date.

Attributes

Attribute Effect
data-clr-context-ignore The element and everything inside it is invisible to the engine: never described, never written to, and its mutations and annotations never trigger a re-scrape. Put it on UI that renders the context, so a panel cannot describe itself or loop. Exported as CLR_CONTEXT_IGNORE_ATTRIBUTE.
data-clr-context-redact The control, or every control in the region, is still described — label, type, what it permits — but its value is never reported, never written, and the text the region shows is left out. A component inside publishes only that it is redacted: a datagrid reports neither its rows nor its selection. An annotation inside is reported without its state. Exported as CLR_CONTEXT_REDACT_ATTRIBUTE.

Snapshot options

ClrContextSnapshotOptions. Defaults are in CLR_CONTEXT_DEFAULT_OPTIONS, which, like CLR_CONTEXT_PRESETS and CLR_CONTEXT_CATEGORIES, is frozen: spread it into an object of your own to change it.

Option Default Effect
maxTextLength 100 Longest any single string may be. Anything longer is truncated with an ellipsis.
maxItemsPerCollection 25 Most items reported per collection — rows, tabs, list items, options, menu items.
maxComponents 300 Most components described in total. The walk stops when the budget is spent, so a low value drops whatever comes last in the document — and the snapshot then carries truncated: true.
includeDomComponents true Whether to describe the rendered page at all. Turn it off for route and annotations only.
includeText true Whether visible text that carries no role — a paragraph, a card's body — is reported as text nodes, so what the page says reaches the agent along with what it can do.
includeFrames true Whether same-origin frames are described in place, as frame nodes with the frame's content as children. A cross-origin frame is reported as a frame without children either way.
includeRoutes false Whether to list the routes the application can navigate to (availableRoutes: path patterns from the router configuration, with titles where named), so an agent can propose going somewhere the page does not link to. The application performs the navigation. The list is bounded by maxItemsPerCollection, never to fewer than 50 routes.
excludeCategories [] Kinds of content to leave out by name — layout (header, navigation, footer, side panels), actions, forms, headings, collections, dialogs, status, images, text, frames. Each expands to the roles it covers (CLR_CONTEXT_CATEGORIES).
excludeRoles [] Roles whose whole subtree is left out — ['navigation', 'banner', 'contentinfo'] drops the header, navigation and footer that repeat in every snapshot.
excludeSelectors [] CSS selectors for elements to leave out with their subtree.
rootSelector whole document CSS selector for the element(s) to describe instead of the whole document, e.g. main.
maxDepth 0 (unlimited) Deepest nesting of described nodes, counted from the top.
focus 'page' 'modal': while a modal dialog is open, describe only the dialog; the snapshot then carries focus: 'modal'.
collectionItems 'all' 'summary': collections report counts and current selection only, without item, option or tab lists.

Application-wide options and presets

provideClrContextOptions(preset | options, overrides?) sets the options every snapshot starts from — the engine, the tracker, the frame bridge and the global accessor all read the CLR_CONTEXT_OPTIONS token — with per-call options applied over them. Presets: 'full' (the defaults), 'interactive' (no prose, no navigation/banner/footer) and 'minimal' (no prose or layout, summary collections, shorter text, a lower budget, modal focus). clrContextPreset(name, overrides?) returns a preset with overrides for a single call.

Context shape

ClrPageContext

Property Type Description
title String The document title.
availableRoutes ClrAvailableRoute[] With includeRoutes: the routes the application can navigate to — path, title, and lazy for a route whose children are not loaded yet.
url String The current URL. Frames receive it without its query string or fragment.
route ClrRouteContext Present when the application uses the router: the path pattern, route and query parameters, and the JSON-serializable part of the route data.
regions ClrComponentContext[] What the application said about itself, through clrContext.
components ClrComponentContext[] What is rendered right now, as a tree.
collectedAt String ISO timestamp of the moment the snapshot was taken.
truncated Boolean Present and true when maxComponents ran out before the whole page was described.
focus 'modal' Present when focus: 'modal' narrowed the snapshot to the open modal dialog.

ClrComponentContext

Property Type Description
type String The ARIA role describing what this is — grid, dialog, tablist, combobox. The same word whatever library rendered it.
element String The tag that rendered it, when that says something the role cannot — so a clr-side-panel and a clr-modal stay distinguishable while both being dialogs.
label String Its accessible name.
state Object What is true of it right now: expanded, selected, invalid, sort, value, options, description, and redacted where a value is withheld.
children ClrComponentContext[] What it contains, where that structure matters. A button or link is a node here, not a separate top-level list: to find what a dialog offers, read the dialog's own children.
ref String The handle the mutation engine accepts for this node — e4k9x2m7q. Present only on nodes the engine may be able to write to, and only while the application has provided a mutation policy. Random, so it cannot be guessed, and stable for the same element across snapshots, including a narrower snapshot that left the element out; refused once the element has left the page. Only the engine hands out refs: one in published or extracted context is removed.

Publishing from a component

A component that knows more than its markup shows can say so. The contract lives in @clr/angular/utils rather than here, so publishing costs a component nothing but one import.

Member Returns Effect
publishElementContext(host, callback) () => void Publishes a callback on the host element, returning the teardown to run on destroy. The teardown removes only the callback it published, so republishing is safe. What a component publishes wins over what the markup showed — except a value the engine withheld as sensitive, which is removed again.
publishElementMutator(host, mutator) () => void Says how the component is written to, for the mutation engine. coerce(proposed) turns what an agent proposes into what the form control takes, or refuses with what would have been accepted; write(proposed) writes state that is not a form control, such as a datagrid's selection; read() reads the value back in the agent's terms. Every member is optional. Set ownsContents when the component is written as one thing and what it renders is its own — a combobox's input and options — so those get no refs of their own. Leave it unset when the contents belong to the application: controls in a datagrid's cells keep their own refs.
ClrHostAttribute — For a component that reports an ARIA attribute through a host binding — aria-invalid, role — without overriding the application: an attribute written in the template is kept, and once the application binds its own value, that value wins. new ClrHostAttribute(element, 'aria-invalid').value(computed) from the host binding getter.
