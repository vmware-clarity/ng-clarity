Services

ClrContextualEngineService

Root-provided. Builds snapshots on demand and owns the two ways context leaves the application.

Member Returns Effect
getSnapshot(options?) ClrPageContext Describes the page as it is at this moment. Nothing is cached, so a snapshot cannot report UI that has been closed, destroyed or navigated away from.
registerDomExtractor(extractor) () => void Teaches the collector about markup that carries neither an ARIA role nor an accessible name. Returns a function that removes it again.
enableFrameBridge(options?) void Starts answering context requests from embedded frames. Same-origin only unless told otherwise, and a frame receives neither form values nor the URL's query string unless the host shares them. A frame's budgets are capped at the host's own snapshot budgets.
disableFrameBridge() void Stops answering frames.
requestHostContext(options?) Promise<ClrPageContext | null> For an application that is itself embedded: asks the hosting page for its context. Resolves with null when the host does not answer, so embedded UI degrades gracefully.
enableGlobalAccess(propertyName?, options?) void Exposes window.clrContext() for agents driving the browser. Caller options are reduced to budgets and form values are withheld unless shareFormValues is set, because any script on the page can call it.
disableGlobalAccess() void Removes the global accessor.

ClrContextTrackerService

Root-provided. Turns the pull-based engine into a stream for consumers that always want the current page.

Member Type Effect
context$ Observable<ClrPageContext> Emits whenever the page context actually changes, replaying the most recent snapshot to new subscribers.
currentContext ClrPageContext | null The most recent snapshot, or null before tracking starts.
start(options?) void Takes a snapshot immediately, then watches the DOM for changes and input / change for typing. Calling it again restarts with the new options.
stop() void Stops tracking. The last emitted context stays available.
refresh() void Takes a snapshot immediately and emits it.

ClrContextRegistryService

Root-provided. Holds whatever can contribute application knowledge to a snapshot. Providers are polled at snapshot time and nothing is stored, so an annotation cannot go stale.

Member Returns Effect
register(provider) () => void Registers a ClrContextProvider. Returns a function that unregisters it.
unregister(provider) void Removes a provider, typically from ngOnDestroy.

Directives

[clrContext]

Annotates a region with the knowledge only the application has. Ships in ClrContextualModule.

Input Values Default Effect
clrContext String — What this region is about, in words an agent can use.
clrContextType String 'region' The kind of UI this annotation describes.
[clrContextState] Object null Application state worth knowing, read at snapshot time rather than stored, so it is never out of date.

Attributes

Attribute Effect
data-clr-context-ignore The element and everything inside it is invisible to the engine: never described, and its mutations never trigger a re-scrape. Put it on UI that renders the context, so a panel cannot describe itself or loop. Exported as CLR_CONTEXT_IGNORE_ATTRIBUTE.
data-clr-context-redact The control, or every control in the region, is still described — label, type, what it permits — but its value is never reported. Exported as CLR_CONTEXT_REDACT_ATTRIBUTE.

Snapshot options

ClrContextSnapshotOptions. Defaults are in CLR_CONTEXT_DEFAULT_OPTIONS.

Option Default Effect
maxTextLength 100 Longest any single string may be. Anything longer is truncated with an ellipsis.
maxItemsPerCollection 25 Most items reported per collection — rows, tabs, list items, options, menu items.
maxComponents 100 Most components described in total. The walk stops when the budget is spent, so a low value drops whatever comes last in the document.
includeDomComponents true Whether to describe the rendered page at all. Turn it off for route and annotations only.

Context shape

ClrPageContext

Property Type Description
title String The document title.
url String The current URL. Frames receive it without its query string or fragment.
route ClrRouteContext Present when the application uses the router: the path pattern, route and query parameters, and the JSON-serializable part of the route data.
regions ClrComponentContext[] What the application said about itself, through clrContext.
components ClrComponentContext[] What is rendered right now, as a tree.
collectedAt String ISO timestamp of the moment the snapshot was taken.

ClrComponentContext

Property Type Description
type String The ARIA role describing what this is — grid, dialog, tablist, combobox. The same word whatever library rendered it.
element String The tag that rendered it, when that says something the role cannot — so a clr-side-panel and a clr-modal stay distinguishable while both being dialogs.
label String Its accessible name.
state Object What is true of it right now: expanded, selected, invalid, sort, value, options, description, and redacted where a value is withheld.
children ClrComponentContext[] What it contains, where that structure matters. A button or link is a node here, not a separate top-level list: to find what a dialog offers, read the dialog's own children.

Publishing from a component

A component that knows more than its markup shows can say so. The contract lives in @clr/angular/utils rather than here, so publishing costs a component nothing but one import.

Member Returns Effect
publishElementContext(host, callback) () => void Publishes a callback on the host element, returning the teardown to run on destroy. The teardown removes only the callback it published, so republishing is safe. What a component publishes wins over what the markup showed — except a value the engine withheld as sensitive, which is removed again.
