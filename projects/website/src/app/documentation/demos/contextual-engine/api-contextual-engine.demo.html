Most applications need only a few of these: ClrContextEngineService or ClrContextTrackerService to read the page, and data-clr-context-redact for fields that hold secrets. Everything else is for finer control.

Services

ClrContextEngineService

Reads the page on demand and returns it as a snapshot.

Member Returns Effect
getSnapshot(options?) ClrPageContext Describes the page as it is right now. Nothing is cached.
registerDomExtractor(extractor) () => void Describes custom markup the engine cannot understand on its own, such as an element with no role and no name. The extractor's answer replaces the element and everything inside it. Returns a function that removes the extractor.
enableGlobalAccess(propertyName?, options?) void Adds window.clrContext(), for browser agents and extensions. Any script can call it, so the caller is untrusted (see Untrusted callers below). An assistant built into the application does not need it.
disableGlobalAccess() void Removes window.clrContext().

ClrContextTrackerService

Keeps the snapshot up to date as the page changes, as a stream. Use it for a chat panel that always needs the current page.

Member Type Effect
track(options?) Observable<ClrPageContext> The easiest way to use the tracker: tracking runs while anyone is subscribed and stops when the last subscriber leaves. There is one tracker, so its options apply to every subscriber.
context$ Observable<ClrPageContext> Emits each new snapshot when the page changes. New subscribers get the latest one at once.
changes$ Observable<ClrContextChange> Emits what changed since the previous snapshot (nodes added, removed and changed), so a conversation can send the difference instead of the whole page. clrDiffContext(previous, current) does the same comparison on demand.
currentContext ClrPageContext | null The latest snapshot, or null before tracking starts.
isTracking Boolean Whether the tracker is running.
start(options?) void Starts tracking by hand. A snapshot is taken once the page has been quiet for debounceMs (300 by default), and at least every maxWaitMs (2000 by default) while it keeps changing.
stop() void Stops tracking. The latest snapshot stays available.
refresh() void Takes a snapshot now and emits it.

ClrContextRegistryService

Adds context that is not on the page, such as a workflow model held in a service. Register an object with a getClrContext() method, and the engine calls it on every snapshot. The answer appears in the snapshot's regions. [clrContext] uses this service itself, so most templates need only the directive.

Member Returns Effect
register(provider, element?) () => void Adds a provider and returns a function that removes it. Pass an element to tie the provider to it: when the element is hidden or ignored, the provider's context is left out too.
unregister(provider) void Removes a provider, typically in ngOnDestroy.

Directives

[clrContext]

Adds what only the application knows to a part of the page. Standalone: import ClrContext, or ClrContextModule in an NgModule.

Input Values Default Effect
clrContext String — What this part of the page is about, in plain words.
clrContextType String 'region' What kind of UI it is.
[clrContextState] Object null Application state worth knowing. Keep it small, and pass a new object when it changes.
[clrContextPublicKeys] String[] null The state keys untrusted callers may see. Without it they see none of the state (see Untrusted callers below).

Attributes

Hiding content

Password and file inputs, and inputs with autocomplete set to current-password, new-password, one-time-code or a cc- value, are always withheld. Mark other secrets, such as API tokens or private keys in plain text fields.

Attribute Effect
data-clr-context-redact The field, or every field inside the element, is still described (its label and type), but its value and the text it shows are never read or written. Exported as CLR_CONTEXT_REDACT_ATTRIBUTE.
data-clr-context-ignore The element and everything inside it is invisible to the engine. Put it on the chat panel itself, so the assistant does not describe its own conversation. Exported as CLR_CONTEXT_IGNORE_ATTRIBUTE.

Snapshot options

ClrContextSnapshotOptions, passed to any method that takes a snapshot. Set them once for the whole application with provideClrContextOptions.

Option Default Effect
focus 'page' 'modal' describes only the open modal dialog, or the whole page when no dialog is open, so it can be set once for the whole application.
rootSelector whole document A CSS selector for the part of the page to describe, such as main.
excludeCategories [] Kinds of content to leave out: layout (header, navigation, footer, side panels), actions, forms, headings, collections, dialogs, status, images, text, frames.
excludeRoles [] ARIA roles to leave out, with everything inside them, such as ['navigation', 'banner'].
excludeSelectors [] CSS selectors for elements to leave out, with everything inside them. This only trims the snapshot; to keep something from agents, use data-clr-context-redact or data-clr-context-ignore.
maxComponents 300 The most nodes to describe. When it runs out, the rest of the page is left out and the snapshot has truncated: true.
maxItemsPerCollection 25 The most items to list per collection: rows, tabs, list items, options, menu items.
maxTextLength 100 The longest a single string may be before it is cut.
maxDepth 0 (unlimited) The deepest nesting to describe.
collectionItems 'all' 'summary' gives counts and the selection only, without listing rows, options or tabs.
includeText true Whether to include plain text, such as paragraphs and card bodies.
includeRoutes false Whether to list the application's routes in availableRoutes, so an agent can suggest going to a page that is not linked from the current one.
includeFrames true Whether to include embedded frames. A same-origin frame is described with its content; a cross-origin frame only by its name.
includeDomComponents true Whether to describe the page at all. Turn it off to get only the route and annotations.

Application setup

Function Effect
provideClrContextOptions(preset | options, overrides?) The snapshot options every snapshot starts from. Presets: 'full' (the defaults), 'interactive' (no plain text, no layout) and 'minimal' (also summary collections, shorter text, fewer nodes and modal focus). clrContextPreset(name, overrides?) returns a preset for a single call.

Untrusted callers

The application's own code sees everything. window.clrContext() is untrusted, because the application does not control who calls it. Its callers get less:

  • No values the user entered or chose (typed text, selected options and rows, ticked boxes), unless the application sets shareFormValues. A withheld value is marked withheld: true.
  • No full URL or page title, only the route pattern such as clusters/:id, unless the application sets shareFullUrl.
  • Published state only under the keys listed in publicKeys. A key nobody listed stays private.
  • Only safe options (budgets, categories, roles, focus), never selectors, and never more than the application allows.

Snapshot

What every snapshot method returns.

ClrPageContext

Property Type Description
title, url String The document title and the current URL.
route ClrRouteContext With the router: the route pattern, its parameters, the query parameters and the route data.
availableRoutes ClrAvailableRoute[] With includeRoutes: the routes the application can go to.
components ClrComponentContext[] What is on the page right now, as a tree.
regions ClrComponentContext[] What the application added through [clrContext] and ClrContextRegistryService.
collectedAt String When the snapshot was taken, as an ISO timestamp.
truncated Boolean true when something was left out because a limit was reached.
focus 'modal' Present when the snapshot describes only the open modal dialog.

ClrComponentContext

One node of the tree.

Property Type Description
type String The ARIA role, such as grid, dialog or combobox. Plain text is text.
element String The tag, when it says more than the role, such as clr-side-panel or clr-modal for two dialogs.
label String Its accessible name.
state Object What is true of it now, such as expanded, selected, invalid, value, error or rows.
children ClrComponentContext[] What it contains. A dialog's buttons are among its children.

Publishing from a component

For component authors: say what a component knows that its markup does not show. These live in @clr/angular/utils. An element holds one published context, so do not publish on an element that already publishes; use a wrapper element.

Member Returns Effect
publishElementContext(host, callback) () => void The engine calls callback on every snapshot and merges its answer into the host's node. Returns a function to call on destroy.
usableSelectors(root, selectors) string Joins the valid selectors into one and drops invalid ones.
CLR_CONTEXT_DEFAULT_MAX_ITEMS number How many items to list when the caller sets no limit: 25.

ClrPublishedContext

What publishers, extractors and providers return: a ClrComponentContext with one more field.

Property Type Description
publicKeys readonly string[] The state keys untrusted callers may see. None by default. Each child lists its own.

Member Effect
