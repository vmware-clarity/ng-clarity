Basic Example

This example allows multiple files to be selected. You can remove the multiple attribute to allow only a single file to be selected.

Disabled Example

The native disabled attribute can be applied to the file input element.

Validation Example

Several validations are supported out of the box:

  • Required: Use the native required attribute on the file input element. The validation will pass if at least one file is selected.
  • File type: Use the native accept attribute on the file input element. It is recommended to include both file extensions and MIME types for the best browser and OS support. The validation will pass if all selected files match an accepted file extension or MIME type.
  • File size: Use the [clrMinFileSize] and [clrMaxFileSize] inputs on the file input element. The validation will pass if all selected files are within the given range (measured in bytes). If only the min or the max file size is specified, the allowed file size range will be open ended.

Value Accessor Example

Since the file picker uses the native file input element, you can use native browser behaviors and API to read and upload the selected files. To assist you, the file picker provides a custom value accessor to set the Angular form control value to the selected FileList

Custom Button Label Example

The file picker button text can be customized using the clr-file-input-container component's [clrButtonLabel] input.

Advanced File Picker Example

This example shows the advanced file picker. This mode will show each selected file via the clr-file-list component. Each file can have its own message text. Disabling the file picker and validation works the same as the examples above. Setting a custom browse button label is also possible as shown above, but the button text won't change based on the selected files.
