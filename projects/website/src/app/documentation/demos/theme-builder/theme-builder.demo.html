ThemeBuilderComponent is a standalone, embeddable UI for customizing Clarity's color tokens (primary, info, success, warning, danger) across the light and dark theme, previewing the result live, and exporting a CSS override file.

Design

Inputs & Outputs

  • [presets] — the list of named color presets shown in the preset selector. Defaults to Clarity's built-in preset list (PRESETS), exported from @clr/addons/theme-builder so consumers can extend it (e.g. [...PRESETS, myPreset]) instead of replacing it outright. Each preset's light/dark color groups are a Color[] — the same shape used internally — so a preset can specify a full set of tint/shade/dark variants for a group, not just its base color.
  • (generatedCSS) — emits the generated CSS override text (a string) every time a color, preset, reset, or the warning-text-override toggle changes.
  • Content projection — anything projected through <ng-content> renders above the built-in preview. Projected content still renders inside the themed preview sandbox, so it reacts to the light/dark toggle and every color edit exactly like the built-in preview does.

Methods

  • applyPreset(preset) — applies a ThemePreset programmatically, the same way clicking a preset card does.
  • importCSS(css) — re-applies previously generated CSS (e.g. the value a consumer saved from an earlier generatedCSS event) by parsing its per-theme override blocks and applying every token they contain, deriving tint/shade/dark variants for any base color that changed.
  • presetSwatchColor(preset) — returns the hex color for a preset's swatch (its light-theme primary base color), or undefined if the preset doesn't set one. Useful when rendering a custom preset picker instead of the built-in cards.

Limitations

  • The addon doesn't persist the generated CSS itself — display, copy, or save the value emitted through generatedCSS, and hand it back to importCSS() later to restore it.
  • Only the five status/primary aliases (primary, info, success, warning, danger) and their computed tint/shade/dark variants can be edited.

Methods

Method Returns Description
applyPreset(preset) void Applies a ThemePreset, resetting each token group first. A group's colors are a Color[], so a preset can specify a full set of tint/shade/dark variants, not just the base color — an explicit variant wins over what would otherwise be derived from the base.
importCSS(css) void Re-applies previously generated CSS by parsing its per-theme override blocks and applying every token they contain, the same way a preset is applied.
presetSwatchColor(preset) string | undefined The hex color for a preset's swatch (its light-theme primary base color), or undefined if the preset doesn't set one.
